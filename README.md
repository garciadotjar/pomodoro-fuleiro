## Ideia inicial

O **Pomodoro Fuleiro** nasceu para melhorar o estudo com a técnica Pomodoro, mas sem a rigidez de um timer que te manda parar no meio de uma boa sessão de estudos.

A ideia do Pomodoro Fuleiro foi inspirada pelo [Sween](https://www.youtube.com/@HenriqueSween)

> **O método Pomodoro** foi criado por Francesco Cirillo. A ideia é dividir o estudo em blocos de foco (tradicionalmente 25 minutos) separados por pausas curtas (tradicionalmente 5 minutos). Isso ajuda a manter a concentração e evita o cansaço de estudar por horas sem parar.

---

## Funcionamento do app

O app reúne tudo que você precisa para uma sessão de estudo em uma única janela:

- **Timer Pomodoro** com tempo de estudo e de descanso **configuráveis**.
- **To-do list** para organizar o que precisa ser estudado.
- **Lo-fi de fundo** para ajudar na concentração.

### ⭐ O diferencial: você escolhe quando descansar

Quando o tempo de estudo acaba, o app **não te obriga a parar**. Você escolhe:

1. **Iniciar o descanso**; ou
2. **Continuar estudando** e deixar o descanso para mais tarde.

Se você está muito focado em algo, está gostando do conteúdo, ou simplesmente quer continuar, por que parar? O app respeita o seu ritmo.

## Como baixar
EM DESENVOLVIMENTO


Os instaladores e o `.jar` estão na página de **[Releases](https://github.com/garciadotjar/pomodoro-fuleiro/releases)**.

| Formato | Para quem | Como instalar / rodar                               |
|---|---|-----------------------------------------------------|
| `.deb` | Debian, Ubuntu e derivados | `sudo apt install ./pomodoro-fuleiro-installer.deb` |
| `.rpm` | Fedora, openSUSE e derivados | `sudo dnf install ./pomodoro-fuleiro-installer.rpm` |
| `.exe` | Windows | Baixe o arquivo e dê dois cliques para instalar     |
| `.jar` | Qualquer sistema com Java instalado | `java -jar pomodoro-fuleiro-universal.jar`          |
